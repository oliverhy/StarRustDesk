# 紧凑远控二级菜单

## 修改范围

- 屏幕菜单为一排可横向滚动的屏幕按钮，移除重复标题、“当前屏幕”说明和网格布局。默认字号、三个屏幕时为 198 × 62 vp；保留淡蓝选中、切换和长按排序。
- 输入、画面、更多使用单列左对齐选项；普通项透明背景，选中项淡蓝。只计算并显示当前设备/远端实际可用的选项，不保留隐藏按钮的空位。
- “画面/更多”取消 168/176 vp 的固定最低宽度，按当前窗口所属 UIContext 测量已翻译标签（13 fp、600 字重），只添加 18 vp 外框、每侧 8 vp 选项内边距和 4 vp 边框/取整余量。仅保证手机/平板 44 vp、PC 38 vp 的最小点击宽度；字号与点击高度不缩小。示例：65/78 vp 的标签对应 103/116 vp 菜单，不是所有机型的固定尺寸。“输入”仍保留 224 vp 和既有 12 vp 内边距。
- PC“画面”的比例行与滑块单独保留 224 vp 基础空间；其他部分不继承它。长标签和大字体按测量结果加宽，再限制在窗口内和 380 vp 上限；受限时沿用两行文字、字体自适应及纵向滚动。宽度测量失败时使用保守估算，不影响菜单或远端输入。
- 测量缓存随语言、字体、窗口尺寸、密度、可见选项及聊天未读数量变化更新，不按机型写死、不每帧重复测量。开/关、全屏切换、隐私屏处理中等状态文案一起预留，避免点击后突然变宽；仅调整“画面/更多”，触摸行高、弹出定位、其他菜单宽度不变。
- 手机和平板触摸目标至少 44 vp；PC 常规菜单行至少 38 vp。大字体增加行高与宽度，过长文字允许两行；选项超出可用高度时滚动，不压缩为难以点击的小按钮。
- 弹出位置使用被点击按钮的实际坐标。按钮拖动、旋转、折叠展开、分屏、自由窗口、PC 沉浸/全屏和窗口位置变化后重新计算，并限制在当前可用页面内。
- 保留页面原有系统安全区。软键盘占用高度按所属窗口的密度换算，兼容页面已经缩短与未缩短两种情况，不重复减去键盘高度。
- 横向、纵向二级菜单均隐藏滚动条，但仍可滑动。内容宽高统一扣除 8 vp 内边距和 1 vp 外框的两侧占用，避免选中背景左右边缘和最后一行底部被 Scroll 裁切；移除原先为横向滚动条保留的空白条。
- 输入菜单的模式项改为“鼠标 / 触摸”双选切换。采用 Material 实体鼠标/手指图标，16 vp 图标与 13 fp 文字作为一组居中，与其他菜单字号一致；未选项去掉外框，选中项保留淡蓝底和细边。不再使用小箭头或文字占满剩余宽度的布局。只缩小视觉内容，点击区域和菜单行高不变。窄窗口和大字体下自动改为上下排列，尺寸计算同步增加所需行高。点击已选模式不反向切换；沿用现有 `setInputMode` 的手势清理、相对模式处理和偏好保存，保留长按排序及无障碍选中说明。
- 点击菜单外、返回或 Escape 仍只关闭本地菜单，不把这一操作转发给远端。按钮动作、排序和输入协议不变。
- “边缘跟随”和“移动画面”使用同一可见性规则：不能平移时都不渲染、也不参与高度/宽度计数。未放大时的 5 项菜单内容高度为 `5×44 + 4×2 = 228 vp`，不再预留第 6 项；Scroll 和内部 Column 显式顶部对齐，避免剩余空间均分到上下。
- 卡片和遮罩共用动画进度，展开/收回都是 160 ms、EaseInOut、透明度 0↔1，卡片缩放 0.97↔1。展开在挂载后的下一帧开始；收回保留菜单类别和遮罩到完成回调，期间禁用卡片动作并继续隔离远端输入，再移除菜单。快速开关/切换和离开页面以 epoch 丢弃旧回调，断开及页面退出立即清理；系统动画 API 不可用时安全完成打开或关闭，不留下不可见的遮罩。

## 跨设备策略与验证边界

不按型号或物理分辨率写死布局。手机、双折叠、三折叠、Pura X/Pura X Max 等宽比例折叠形态、平板和笔记本使用当前逻辑窗口尺寸与字体设置计算。折痕/铰链及外接屏的特殊布局仍取决于系统向应用提供的有效窗口和安全区。

自动测试用合成 vp 窗口覆盖窄外屏、内屏、宽屏、方屏、多折展开、平板、PC、分屏和键盘压缩，并检查 1～3.2 倍字体、多个显示器及四个边缘的定位。这些不是各型号的实际测量数据，也不能替代对应设备的真机验收。

需真机检查：不同机型折叠/展开与旋转后菜单是否在屏内；大字体文字和点击区域；显示器选择横向滚动；PC 窗口拖动/缩放；输入法打开时菜单避让；所有按钮动作和外部关闭不误操作远端。

本次不更新版本、不提交发布、不自动断开当前远控会话安装。

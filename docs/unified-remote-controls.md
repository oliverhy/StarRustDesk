# 远控操作栏整合

1.2.22 引入整合菜单，1.2.23（1002023）统一各尺寸的悬浮位置与收放，并按远端记住偏好；自动测试与真机验收的边界见下文。

- 主入口统一为：屏幕、输入、键盘、画面、更多、断开。手机与平板横竖屏均在底部横向排列；PC 普通大小窗口与全屏均为顶部居中的横向悬浮栏。所有尺寸均支持收起为“控”，并保存拖动位置。
- 屏幕：显示器选择；输入：鼠标/触摸切换、虚拟鼠标、Android 操作、手势说明、剪贴板；画面：边缘跟随、平移、缩放、全屏、画中画、旋转；更多：聊天、文件、录像、隐私屏、连接信息、排序。
- 键盘主按钮一键开关本地软键盘，旁边下拉按钮展开组合键。原修饰键逻辑、更多按键及排序保留。工具栏折叠时手机独立键盘按钮仍可使用。
- 菜单沿用淡蓝色选中、半透明浅色/深色面板与圆角线性图标；有打开/关闭过渡。关闭菜单的点击不传给远端，菜单打开时暂停实体键鼠转发。
- 连接信息默认不显示独立入口，改从“更多 → 连接信息”开关；展开后仍可拖动和关闭。
- PC 的“画面 → 沉浸窗口”是可选项，隐藏标题栏，保留拖动区、最小化、退出沉浸、断开入口；功能栏仍可收起，真全屏的独立退出按钮继续保留。系统窗口圆角和阴影由系统决定。
- 沉浸和全屏系统操作串行，离开远控后恢复原标题栏可见状态。未更改物理键位映射、手机触摸坐标和网络协议。

## PC 窗口与缩放补充

- “画面”菜单新增适应窗口、原始比例、自定义三种模式。默认适应窗口，等比完整显示；比例不同时允许留边，不裁切、不拉伸。
- 原始比例为 100% 物理像素显示尺寸；自定义为 25%～300%，可使用滑条及现有 +/- 按钮。调整窗口尺寸、切换显示密度或远端分辨率后，原始/自定义模式保持所选显示比例，平移仍受画面边界约束。
- 滑条及 +/- 围绕当前视野中心缩放，不把黑边当作缩放中心。手机/平板继续使用原有缩放和触摸操作路径。
- “调整窗口”手动按远端比例及本地标题/侧栏占用计算窗口大小，限制在显示器可用区域内；完成后切换到适应窗口。不会持续锁定窗口比例。需先退出最大化或全屏；系统不支持或操作失败时显示提示，不假报成功。
- PC 各窗口模式均提供“自动收起 / 已固定”开关，未固定时在远端画面内停止操作约 5 秒后折叠为“控”；菜单、按键拖动、功能栏拖动、失焦时不收起。真全屏的右上角退出入口保留，窄窗口默认避让。位置及恢复策略见 [remote-toolbar-placement.md](remote-toolbar-placement.md)。
- 监听主窗口激活/失活，切去本机应用后释放按住的鼠标键、普通键和修饰键，恢复本机系统指针，并暂停本窗口的键鼠转发及全局键位轮询。返回后仅在原来操作远端时恢复远控输入焦点，不抢占本地菜单/文件/聊天焦点。
- 补充 `remote-window` 脱敏日志：显示模式、比例、窗口调整、输入释放/焦点恢复和 API 失败；不记录键入内容。

验证：新增 `tools/test-desktop-window.cjs` 使用实际生产逻辑与模拟窗口 SDK，覆盖缩放/密度、视野中心、工作区边界、失焦输入、工具栏自动收起、窗口排队与过期请求；需实机验收普通/最大化/沉浸/全屏、QQ 往返、多显示器和高 DPI。

自动测试不代表真机验收。设备上需检查：手机大字体菜单、横竖屏与键盘避让、PC 普通/沉浸/全屏往返、窗口拖动和最小化、菜单点击不误发远端、画中画进入与恢复。

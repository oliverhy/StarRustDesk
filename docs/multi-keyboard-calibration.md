# 多键盘与 Mac 修饰键校准

远控连接中进入“控 → 输入 → 键盘设置”，选择“苹果布局修正”，点击“校准 Command / Option”。在目标实体键盘上依次按下、松开左 Command 和左 Option，然后确认并保存。校准事件仅在本地处理，不向远端发送。

- 依据鸿蒙输入事件的设备 ID 为每个已校准的输入设备分别应用修正，不根据设备名称或品牌猜测键位。
- 如果系统将同一把键盘的两个按键报告为不同设备，界面要求用户确认两次操作来自同一把实体键盘；确认后才同时校准这两个设备。
- 稳定且在当前设备列表中唯一的硬件指纹可恢复校准；缺少稳定标识或存在指纹冲突时，仅在当前设备清单有效期内保存，设备变更后需重新校准。
- 无法可靠识别事件来源时，不将其他键盘的校准强行套用。系统只提供无法归属的全局修饰键状态时，不猜测该状态来自哪把键盘；直接设备事件可恢复正确状态。
- 自定义按键映射仍按远端保存并优先于布局校准；软键盘、输入法文字、粘贴和快捷栏不应用实体键盘布局修正。不同键盘同时按住修饰键时分别跟踪，设备变更、失焦或断线会释放已发送的按键。
- 扩展屏键盘事件通过相同的设备识别与修正链路，保留失焦自动释放。

诊断记录只包含设备数量、校准与策略状态、来源是否可识别和失败阶段，不记录设备标识、按键名称、扫描码或输入内容。旧版已导出的日志仍可能包含扫描码，应避免公开分享。

自动化覆盖多设备校准、身份冲突、断连、按键释放、输入法和快捷键；还需要在实际鸿蒙设备、苹果外接键盘和 Mac 被控端上验证，尤其是复合键盘的设备 ID、组合键以及设备拔插后的行为。

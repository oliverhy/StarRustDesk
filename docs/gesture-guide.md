# 图解手势指南

- 远控内的手势说明使用“动作 → 结果”卡片，分别预览鼠标模式与触摸模式；打开时初始展示当前输入模式。切换预览不修改实际输入模式或保存设置。
- 鼠标模式展示虚拟鼠标的左右键、上下滚动、中键和底部移动区；轻点后再次按住并移动为左键拖拽，长按或双指轻点为右键。触摸模式展示在目标上点按、双击及立即按住移动。
- 两种预览均说明双指滚动、捏合缩放、三指左右切屏和全屏三指上滑打开键盘。三指切屏仍要求远端多屏、开关开启且系统向应用交付触控事件；触控板和被系统拦截的手势不作支持承诺。
- 投屏、拖拽框选、组合键、实体键盘布局、移动画面和画面跟随等详细说明按原段落拆成带主题图标的图文卡片，保留原有内容和条件。支持英文与繁体中文；图形为本地 SVG，适配深浅色背景，文字按容器换行。
- 本地资源和测试覆盖不同模式文案、预览不改设置、虚拟鼠标映射、多语言及可滚动布局；截图效果、大字体、横竖屏及不同机型仍需要真实设备验收。

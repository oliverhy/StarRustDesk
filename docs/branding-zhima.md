# 芝麻远控品牌更新

本次由 StarRustDesk 更名为“芝麻远控”，仅更新对外品牌，不新建应用、不迁移用户数据。简体与英文界面沿用“芝麻远控”，繁体界面显示“芝麻遠控”；未另行设定英文商标名。

## 修改范围

- 桌面与任务窗口名称、连接页标题、远控窗口标题、更新提示、系统媒体信息、投屏和云同步引导。
- 远端可见的登录客户端名称、录制文件的应用名称元信息、导出日志抬头。
- 新导出的连接备份、批量下载压缩包和诊断日志的默认文件名。旧文件名仍可导入，文件扩展名不变。
- 桌面/任务窗口单层图标、启动图标、备用启动图标及分层图标的前景/背景资源。
- 启动背景由旧品牌纯蓝色调整为浅色灰白/深色背景，应用内部主题配色不变。
- README 和简体、繁体、英文三套应用市场资料。
- 正式包导出文件名读取应用显示名称；构建工程名与签名输入不变。

## 兼容性边界

| 项目 | 保持不变的内容 |
| --- | --- |
| 应用身份 | `com.yinhe.starrustdesk`、原应用记录/App ID、证书、签名密钥及 profile |
| 连接与设置 | 原存储目录、配置文件名、选项键、分组/连接 ID、按远端保存的设置 |
| 密码与账号 | `starrustdesk.connection.*`、`starrustdesk.os-login.*`、`starrustdesk.api.account.v1*` |
| 本地配置加密 | `SRDCFG1`、原 salt、设备密钥派生前缀与路径 |
| 备份文件 | `StarRustDeskConnectionBackup`、`StarRustDeskEncryptedConnectionBackup`、schema 1、AAD、PBKDF2 参数、`.json`/`.srdbak` |
| 云端备份 | 应用云目录下的 `StarRustDesk` 文件夹、`StarRustDeskCloudSnapshot`、v1/v2 文件名规则与 `.srdsync` |
| 项目与历史 | GitHub 地址、工程目录、内部资源 ID、日志标签、历史发布记录及旧宣传源文件 |

不需要重命名或重新加密任何现有备份，不新增启动时数据迁移或清理逻辑。正式发布应在原应用记录下使用相同签名覆盖升级，不能卸载旧应用后安装；此前调试包与正式包的云空间身份差异不在本次修改范围内。

## 图标来源与导出

源文件为用户提供的 `未命名.svg`，原样保存在 `design/branding-zhima/source.svg`。图案、图层位置和颜色不重绘。导出时仅去掉横向文档空白，并将原灰白渐变延伸到方形四角，生成 1024×1024 RGB PNG；圆角由系统处理，单层图标不存在透明像素。分层前景保留透明通道，背景不透明。

使用 `tools/export-branding-icons.cjs` 可重复导出；需要构建环境中的 `sharp`，不会打包进应用。原有资源 ID 不变，图标保真打包钩子继续保留。

- 调试 HAP 已通过 SDK `verify-app` 签名与原生库代码签名校验；这不是新的应用市场正式签名 APP，也未安装到设备。
- `tools/test-branding-compatibility.cjs` 使用隔离的模拟数据验证旧普通备份、旧加密备份、密码和 API 会话读取，并锁定身份/内部命名空间。
- 图标测试验证方形、不透明、批准的前景配色、启动资源一致性及打包保真。
- 云同步状态机、密码保护、主题及连接设置继续运行原回归测试，不访问真实用户云盘。
- 上述初次验证未改变版本号、未安装设备或发布；随后获用户授权将本次品牌修改随 `1.3.13（1003013）` 正式发布，具体记录见 [版本说明](releases/1.3.13-1003013.md)。

# 系统画中画

连接成功并收到画面后，在远控工具栏或 PC 右侧功能栏打开“画面”，点击“画中画”（全屏按钮附近）。入口参与该分类内的自定义排序。

- 使用系统 PiPWindow 与当前 XComponentController，不申请普通悬浮窗权限、不复制屏幕或另建解码器。
- 手动开启，不因切后台自动弹出。设备不支持或系统关闭应用画中画权限时显示提示。
- 小窗用于观看远端画面；移动、缩放、恢复与关闭由系统提供，具体形态取决于设备和系统版本。控制远端请恢复主窗口。
- 系统“恢复”按钮、主界面“返回主画面”或“关闭小窗”均可回到正常画面。关闭小窗本身不主动断开远控，随后沿用现有后台会话策略，不保证无限后台保活。
- 画中画期间豁免后台停止视频解码的策略；关闭后恢复原策略。真实音频、文件传输和后台任务模式不被伪造或改变。
- 小窗复用视频 Surface，不包含主界面的虚拟鼠标、工具栏和本地光标叠加层。
- 远控结束/离开页面时关闭小窗。启动、关闭和页面销毁串行处理，防止迟到的创建结果显示旧会话。
- 返回主界面时安全重绑定并请求关键帧；主页面的布局变化不抢占画中画 Surface。远端分辨率变化会更新小窗内容比例。

## 验证范围

`tools/test-picture-in-picture.cjs` 运行真实 ArkTS 服务逻辑、模拟系统 SDK，覆盖启动、权限、重复操作、异步取消、系统关闭/恢复、失败重试、分辨率变化和后台策略。此测试不能替代真实系统窗口验证。

真机验收：

1. PC 连接远端 → 画中画 → 切 QQ，确认小窗画面仍刷新。
2. 系统恢复主窗口，确认画面、实体鼠标和键盘恢复；重复 5 次。
3. 在后台关闭小窗后回应用，确认画面恢复；关闭小窗不主动断开。
4. 启动中断开、切换远端分辨率、网络断线和重新连接，不显示上次会话。
5. 手机/平板重复以上操作，并检查系统禁用画中画后的提示。

随 1.2.22（1002022）发布；本说明中的真机验收边界仍适用。

# 远端二次验证与可信设备

芝麻远控支持 RustDesk 1.5.3 的可信设备 V2 协议，以及旧版被控端的旧式可信设备流程。远端须使用永久密码、启用二次验证并允许可信设备；实际行为由被控端配置和安全策略决定。

V2 仅在服务器签名、远端身份和加密通道均已验证的连接上启用。IP/域名明文直连或用户确认的未加密连接不发送可信设备凭证，也不提供可信设备勾选。凭证由鸿蒙关键资产服务保存在本机，禁用同步；存储索引按远端 ID、服务器配置和已验证的远端公钥隔离。更换服务器或远端密钥后需要重新验证。

只有用户在当前会话勾选信任、验证码验证成功且被控端签发有效凭证时，才保存 V2 凭证。遇到系统安全存储不可用或保存失败，保留普通验证码登录并提示用户；失效或被撤销的凭证仍需根据被控端提示重新验证。出于安全考虑，不因旧版全局信任开关自动接受未主动请求的 V2 迁移凭证。旧版被控端仍使用原有可信设备标识。

可信设备属于当前安装与本机系统安全存储，不加入应用连接备份或云同步；卸载、系统清理或更换设备后可能需要重新验证。诊断仅包含准备、二次验证和保存阶段及固定结果，不记录验证码、密码、凭证、存储索引或原始响应。

# 按远端设备记住远控偏好

本地以“配置的 ID 服务器地址 + 远端 ID / 直连地址”作为身份。服务器地址忽略首尾空白与大小写，远端标识去除粘贴空白，IPv4/IPv6 标点完整保留；公共服务器命名空间与自建服务器分开，使用编码后的元组避免分隔符碰撞。身份在远控页进入时固定，不因运行中更改服务器配置而把旧会话偏好写入新设备。

记住的项目：

- 鼠标/触摸模式、本地光标显示、虚拟鼠标和边缘跟随。
- 键盘兼容模式、相对鼠标、远端光标来源；远端不支持的功能仍按能力检查限制。
- “控”和“键”功能栏的位置、排序、收放；“更多”按键的独立排序。
- PC 固定/自动收起状态、适应/原始/自定义画面模式和自定义比例。
- 手机与平板的缩放比例，在捏合结束后记录；不会记录逐帧平移位置或触摸数据。

未做独立修改的项目沿用旧的全局默认值或对应的旧设备键鼠偏好。远控页内的修改只写当前设备记录，不再回写全局默认值。此功能不改变连接信息、画质预设、账号、密码、隐私屏或云同步策略。

每台远端是一个选项文档。连续修改合并为一次写入；拖动结束及离开远控页时刷新待保存数据。日志仅包含恢复/保存结果与项目数量，不包含服务器地址、设备 ID、选项值、密码或输入内容。

原生配置读取使用完整 UTF-8 键（限制 16 KiB），与写入保持一致；不再用 128 字节固定缓冲截断 IPv6 或较长服务器地址生成的键。此项不改变网络建链路径。

白名单明确排除：按住的 Ctrl/Shift/Alt、鼠标按下、输入法编辑内容和开关、当前菜单、全屏/无边框状态、正在运行的任务。损坏记录和越界数值被忽略，不可用存储不应中断远控。

位置按可拖动范围的相对坐标恢复；横竖屏、折叠屏、窗口缩放和输入法改变高度后重新限制在可见范围内。旧版本未保存到磁盘的临时位置无法追溯迁移。

测试覆盖同服务器不同设备、不同服务器相同 ID、直连地址、旧默认继承、冷运行恢复、延迟保存、旧会话回调、白名单与存储失败。实机重启及 A/B 设备切换需另行验证。

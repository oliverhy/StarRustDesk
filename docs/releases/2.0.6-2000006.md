# 芝麻远控 2.0.6（2000006）

## 更新内容

1. 优化多行文字输入：检测到换行时先保留原文并提示手动处理，避免直接转换为远端回车。
2. 优化长文字和中文输入处理，保留手动回车与组合键；输入未能加入发送队列时提示处理。
3. 优化连接中断后的重试与备用路径，保留服务器密钥验证和现有加密要求。
4. 完善输入和连接诊断，不记录输入文字、密码或令牌。

## 使用及验证边界

- 多行待处理内容暂存在当前远控页面；关闭页面或进程结束后无法恢复。复制后可核对远端已有内容，再手动粘贴；开启剪贴板同步时，复制内容可能同步到远端。
- 输入成功加入本机发送队列不代表远端已确认收到；不同输入法的语音分段回调和各被控系统的插入行为仍需真机验收。
- 连接重试不更改服务器配置，也不因失败自动关闭密钥校验或加密；某些服务器或中继配置问题仍可能导致连接失败。
- 包名、应用标识、原有正式签名、已保存连接和设置格式保持不变。正式构建及签名核验不等于应用市场审核通过。
- GitHub 沿用公开未签名 HAP 发布方式，需自行签名安装；正式签名 APP 留在本地供应用市场提交。

构建、测试和签名核验结果见[发布核验记录](https://github.com/oliverhy/StarRustDesk/blob/v2.0.6-2000006/docs/releases/2.0.6-2000006-verification.md)。

# 芝麻远控 2.0.10（2000010）

## 更新内容

1. 修复虚拟鼠标在画面边缘或缩放时，指针与实际操作位置不一致的问题；点击和拖拽前同步目标位置。
2. 优化虚拟鼠标与远端光标显示，减少重复箭头，并兼容实体鼠标操作。
3. 修复“控”按钮贴边后仍占用较大触控区域的问题，优化鼠标悬停显示，减少遮挡和重影。
4. 优化连接初期的光标位置处理；在画面未准备好时避免误发虚拟鼠标操作，并完善不记录输入内容的诊断。

## 使用及验证边界

- 在授权调试设备上，主要修复调试版的虚拟鼠标移动和远端悬停已验证；最终修复调试版已覆盖安装并启动，但尚未重连实测。点击、拖拽、缩放及方向变化已通过模拟回归；用户反馈的原设备和远端环境尚未复验。
- 新增诊断包含状态、计数和预测偏差，不记录键盘或输入文字；启用诊断时，既有字段仍可能包含指针坐标。
- 包名、应用标识、正式签名身份及现有连接、设置和备份格式不变。
- GitHub Release 提供未签名 Release HAP，需自行签名安装；正式签名 APP 保存在本地供应用市场提交。

构建、测试和签名核验结果见[发布核验记录](https://github.com/oliverhy/StarRustDesk/blob/v2.0.10-2000010/docs/releases/2.0.10-2000010-verification.md)。

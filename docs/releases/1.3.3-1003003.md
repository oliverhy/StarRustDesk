# StarRustDesk 1.3.3（1003003）

发布日期：2026-10-18。Git 标签：`v1.3.3-1003003`。

## 本次更新

1. 修复新增连接输入和保存时将字母强制转为小写的问题。首页、保存、重新加载和直接连接均保留大小写；大小写不同的自定义 ID 独立匹配连接及密码，IPv6 地址比较仍忽略十六进制字母大小写。
2. 连接建立与远端登录分阶段计时，移除远控页面重复的 30 秒断开判断。通道建立后提供独立的 30 秒登录窗口，同时保留单次尝试 60 秒总上限，重复消息不会无限延长等待。
3. 登录无响应时最多自动重新申请一次中继连接。密码错误、密钥错误、两步验证、后台状态、用户取消及已批准的未加密尝试不触发本次自动重试；不自动降低加密要求。
4. 完善连接诊断：记录通道就绪、首包、密码挑战、登录请求入队、实际网络写入，以及等待阶段、耗时和超时原因。修正原来将“入队成功”记为“登录请求已发送”的日志，避免误判。日志不记录密码、挑战内容或令牌。

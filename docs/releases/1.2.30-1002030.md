# StarRustDesk 1.2.30（1002030）

发布日期：2026-10-12。Git 标签：v1.2.30-1002030。

## 本次更新

1. 远控“控 → 输入”新增“键盘设置”和“鼠标设置”。键盘模式、实体键盘布局、自定义映射集中管理；手势说明保留教程，更新新的设置入口。
2. 新增布局：自动、系统原样、苹果布局修正。按服务器与远端独立保存；自动仅恢复已确认的校准，不依据键盘品牌或名称强制交换按键。
3. 苹果布局支持 Command / Option 校准。依次按下并松开键帽上的左 Command、左 Option，确认后保存。仅修正实体修饰键及对应组合键状态，保留左右键独立状态。
4. 有可靠物理标识的键盘可记住校准；无法稳定识别时只用于本次会话。多键盘、设备查询失败或超时暂停布局修正；拔插和过期弹窗不会把校准套到新设备。更改键盘硬件的 Mac / PC 模式后应重新校准。
5. 自定义映射的明确源键规则优先，不重复套用布局修正。中文输入、粘贴、快捷栏和现有完整组合键保持原路径。打开设置、切换布局和退出校准时平衡松键，关闭设置前丢弃校准期间积压的原生输入。
6. 补充布局识别、应用、校准保存失败、过期校准和设备查询诊断。不记录输入文字、键盘名称、原始物理标识或蓝牙地址；本地校准记录只包含散列标识与是否互换。

# 2.0.0（2000000）发布核验

- 正式 release APP 构建成功，含 ARM64 与 x86_64 原生库；APP 内的正式签名 HAP 与单独核验的 HAP 字节一致。
- APP 外层、内层 HAP 的签名及 release profile 验证通过；证书链、profile 与 1.3.14 相同。官方 APP ALL、HAP_LIST、HAP_INFO 和 HAP 解析通过。
- 包名仍为 `com.yinhe.starrustdesk`；版本、非调试标记、扩展显示 Ability（不对外导出）、编译后的账号三选项和扩展屏页面均已核对。
- 四份图标/启动图与源码 PNG 字节一致，保持不透明 RGB；正式签名、存储、密码、备份和主题相关的 13 个保护文件哈希未变，原有内部存储命名空间保留。
- 完整 JavaScript/原生组件测试入口共 114 组，最终全量运行 114/114 通过。旧测试补齐了新接口的模拟依赖、方法定位边界；Windows 临时可执行文件清理加入有限重试。
- Rust 主机测试使用 `cargo test --locked --offline --lib -- --test-threads=1`，113/113 通过。默认并行运行会因测试共享全局会话状态、诊断回调而失败，随后回调锁中毒导致测试进程退出；本次未把并行测试结果当成通过，也未修改生产逻辑来掩盖测试问题。后续应隔离这些全局状态以支持并行测试。
- 测试通过不代表所有设备、真实第三方账号授权或公网 UDP 路径已完成验收；实机测试边界见本版本更新说明。本轮没有安装到设备，也没有操作远端电脑、修改服务器或上传应用市场。

# StarRustDesk 1.2.21（1002021）修订版 r2

## 本次修复

1. 修复 API 地址簿中的 IPv4、IPv6 及带端口设备被过滤的问题，支持导入和双向同步。同步名称与增删设备时保留本地密码、分组及连接设置，不上传本地密码。
2. 加强地址簿分页完整性校验：同步前遇到重复分页、总数变化或列表不完整会停止操作，避免把漏返回的设备误判为删除。非标准服务器返回的有效设备仍可浏览；没有总数时，同步会继续查询至明确的空页。
3. 修复地址簿“全选”后勾选状态可能反复切换的问题，避免程序更新状态再次触发反向勾选。
4. 合入 PR #3 的跨目录构建及资源编译兼容改进，修正构建模板引用不存在的签名配置；补充回归测试。
5. 更新应用内弹窗、设置中的更新说明及英语、繁体中文文字。同版本覆盖更新后，也会展示本次说明。

## 保留的 1.2.21 更新

- 独立可拖动键盘按钮、连续输入与全屏三指上滑；实体键盘和完整组合键不自动弹出软键盘。
- 应用单独投屏的实体鼠标接收、坐标换算、点击去重与脱敏诊断优化。
- 默认跟随系统旋转锁定，支持本次远控手动固定方向，单独投屏方向独立处理。

- Release HAP 与 APP 构建成功；APP 和内含 HAP 的包名均为 `com.yinhe.starrustdesk`，版本均为 `2.0.8 / 2000008`，HAP 为 `debug=false`、`buildMode=release`。构建有 SDK 兼容性及弃用 API 警告。

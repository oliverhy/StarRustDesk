# StarRustDesk 1.2.28（1002028）

发布日期：2026-10-11。Git 标签：`v1.2.28-1002028`。

## 本次更新

1. 加强重装后的云同步保护：新设备未建立同步基线且没有本地连接、分组或服务器地址时，暂停上传空备份；首次同步存在本机与云端数据时要求确认，避免误覆盖。修改备份密码不再把连接数据标记为新修改，既有同步基线下的主动删除继续同步。
2. “设置 → 华为云空间 → 从云端恢复”新增历史备份列表，按时间降序排列，每页 30 条，可加载更早备份。保留旧格式和历史快照；损坏或未完整下载的备份不可恢复，不静默回退。
3. 恢复前预览时间、连接及分组数量和服务器配置；加密备份输入密码后预览。零连接备份明确警告，用户确认后才恢复；取消不改数据，恢复结果显示实际数量并校验写入结果。
4. 保护过期预览、同步开关变化及恢复期间的本机修改；确认恢复时复查所选备份未变化。历史版本恢复作为新的本机修改同步，防止被较新的空快照再次覆盖。修复首页旧加载任务覆盖恢复后连接的问题。
5. 完善云同步决策、备份列表、加解密、系统同步进度、恢复写入校验和首页刷新诊断。沿用默认关闭的诊断开关，只记录状态、数量、时间、字节数及安全错误码，不记录密码、密钥、服务器地址、备份内容或原始响应。

- 首次升级启动弹窗与设置中的更新日志同步更新，最新版本置顶；首次展示标记为 `1.2.28-1002028`。简体中文、繁体中文和英语说明同步更新。

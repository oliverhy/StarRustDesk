# 芝麻远控 2.0.0（2000000）

## 更新内容

1. 新增鸿蒙 PC 扩展屏：在系统扩展桌面和兼容的远端多屏可用时，将另一块远端屏幕独立显示到扩展屏。支持独立窗口缩放、切屏、触摸、触控板及实体键盘输入；扩展画面支持 VP9、H.264、H.265，实际能力取决于设备和远端。
2. 账号入口拆分为“官方公共服务器”“自建 Server Pro”“第三方 rustdesk-api”。官方地址固定，自动加载第三方登录方式；保留现有自建 API 地址，不自动修改 ID、中继服务器或密钥。
3. 修复身份验证器与邮箱二次验证类型判断，完善网页登录的临时故障重试、取消和超时处理，重做第三方登录按钮，优化错误提示与安全诊断。
4. 新增游戏模式、高性能优先、自定义码率比例和帧率请求，分别展示请求值与实际值。兼容条件下优先尝试 UDP，失败或持续异常时回退 TCP 或中继，保留原有认证和加密。
5. 新增实体、虚拟手柄的键鼠映射，游戏悬浮控制台及可编辑屏幕按键，按远端保存。此功能不是原生手柄透传，实体手柄需要相应系统与设备支持。
6. 改进官方格式服务器配置导入与连接安全提示；未加密连接的七天免提醒仅在用户主动同意后，对指定远端、服务器和风险类型生效。
7. 完善多路解码、切屏、窗口尺寸、按键释放及诊断信息。诊断不记录密码、令牌、验证码或原始响应。

## 兼容性与验证边界

- 包名、应用标识、正式签名身份和连接/密码/设置/云备份的既有存储格式保持不变，升级无需卸载。
- 扩展屏已在此前独立测试版上验证双路 H.264/H.265 画面及触摸、触控板和键盘交互；本次账号三选项界面已在调试设备覆盖升级后验证地址切换、官方登录方式加载及自建地址保留。
- 账号验证码、取消、超时、网络重试及日志脱敏使用模拟回归验证；未使用用户真实账号完成 Google 等第三方授权。
- 游戏模式保持兼容原版 RustDesk，不修改服务器；请求值不是实际性能保证，也不包含 Sunshine/Moonlight 协议或原生手柄透传。
- 实体手柄和更多设备组合仍需实机验证。发布包检查不等于应用市场上传或审核通过。

发布前完整回归 114/114 组、Rust 原生串行测试 113/113 项通过；正式签名、官方包解析及既有存储标识检查通过。详见 [发布核验记录](2.0.0-2000000-verification.md)。

GitHub 下载提供未签名 HAP，需按鸿蒙安装要求自行签名；本地另有正式签名 APP 用于应用市场提交。

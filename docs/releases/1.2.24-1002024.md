# StarRustDesk 1.2.24（1002024）

发布日期：2026-10-09。Git 标签：`v1.2.24-1002024`。

## 本次更新

1. 修复 Mac 自动键盘模式的发送路径混用：Command、Ctrl、Shift、Option 与实体字母、符号、方向键和功能键统一使用 Mac 原生键码映射；区分左右修饰键，保留传统兼容模式、中文输入及完整快捷键发送。
2. 合并原生事件、实体键盘与状态查询重复上报的修饰键按下；实体键盘和快捷栏共同持有同一键时分别释放，避免重复按下或提前松键。
3. 优化焦点丢失、键盘模式切换及离开远控时的按键清理：按实际发送记录补齐松键，保留 Windows Shift 数字符号兼容路径。
4. 修复首次连接时远端 ID 未初始化、独立远控偏好无法持久保存的问题。设置仍按服务器与远端独立存储，不增加密码、剪贴板或按键按住状态的保存。

## 更新说明与边界

- 升级首次启动弹窗与设置中的更新日志同步更新，最新版本置顶，首次展示标记为 `1.2.24-1002024`；提供简体中文、繁体中文和英语说明。
- 本次不改变网络协议、账号权限、远端安全策略或画质配置。
- 自动测试、构建及签名验证不等同于 Mac 实机验收或应用市场审核。建议验证 Command+A/C/V、Ctrl+方向键、Shift+方向键、Shift+数字、左右修饰键及中文输入。
- GitHub Release 仅提供未签名 Release HAP；正式签名 AppGallery APP 留在本地用于上架，不上传 GitHub。

# StarRustDesk 1.2.25（1002025）

发布日期：2026-10-09。Git 标签：`v1.2.25-1002025`。

## 本次更新

1. 分组的“更多”菜单新增删除及二次确认。删除后，分组内全部连接移到“未分组”，包括搜索时隐藏的连接；保留保存的密码、独立操控设置及连接内容。
2. 支持删除空分组；系统“未分组”不可删除。不影响其他分组和正在编辑的连接内容，重复确认或连接保存期间不误执行删除。
3. 优化删除分组的保存顺序与失败处理：先保存连接归属，再删除分组；部分保存失败时明确提示并保留安全重试路径，不误报成功。沿用现有云同步变更标记。
4. 所有分组继续共用现有 ID、名称、在线状态及升降序排序，补充分组内排序一致性回归；本次不新增独立分组排序或改变排序规则。

## 更新说明与边界

- 升级首次启动弹窗与设置中的更新日志同步更新，最新版本置顶，首次展示标记为 `1.2.25-1002025`；提供简体中文、繁体中文和英语说明。
- 本次仅修改分组管理、相关翻译、回归测试及版本说明，不改变键鼠、网络协议、API 账号、密码加密或安全策略。
- 自动测试、构建及签名验证不等同于真机验收或应用市场审核；分组删除确认及多设备云同步传播仍需实际设备验证。
- GitHub Release 仅提供未签名 Release HAP；正式签名 AppGallery APP 留在本地用于上架，不上传 GitHub。

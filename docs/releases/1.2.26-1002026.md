# StarRustDesk 1.2.26（1002026）

发布日期：2026-10-10。Git 标签：`v1.2.26-1002026`。

## 本次更新

1. 已保存连接新增“现有布局 / 精简列表”切换，入口位于标题右侧。精简模式收掉大头像和多余留白，保留在线状态、名称、ID、连接按钮及更多菜单。
2. 手机使用紧凑双行；平板和 PC 宽屏使用单行对齐。按实际列表宽度、窗口尺寸、横竖屏及字体大小自适应，大字体或窄窗口下操作按钮移到独立一行，精简行可随内容增高。
3. 本机记住显示方式，默认保留现有布局，所有分组共用同一视图。视图切换不改变连接、密码、分组、排序、搜索、编辑内容或云同步数据。
4. 优化大字体标题换行和英文连接按钮宽度，沿用深浅色主题及按钮样式。现有与精简视图共用连接和更多菜单的操作路径，保留文件传输、移动、重命名、修改和删除。
5. 显示方式保存失败时明确提示且保留当前视图；补充脱敏诊断及相关回归测试，不记录账号密码或输入内容。

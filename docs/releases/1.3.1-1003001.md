# StarRustDesk 1.3.1（1003001）

发布日期：2026-10-14。Git 标签：`v1.3.1-1003001`。

## 本次更新

1. PC 的“沉浸窗口”开关按服务器与远端 ID 独立记住，重新连接或重启 App 后自动恢复。未设置过的远端默认使用普通窗口；旧版未记录该开关，首次需开启一次保存选择。
2. 窗口切换成功后才保存开关，避免把系统不支持或切换失败当作已启用。保存失败明确提示，当前远控保持可用；现有偏好存储保留重试能力。
3. 退出远控恢复应用原窗口装饰，不将已保存的沉浸开关清空。自动恢复不写回偏好，不影响其他服务器或远端。
4. 恢复等待有效主窗口、全屏、画中画及窗口调整操作就绪。单次连接只尝试一次恢复；失败保留选择，下次连接可重试，避免轮询时反复切换或重复提示。
5. 增加异步会话保护，退出、断线或偏好所属远端变化后的旧回调不保存设置。手机、平板和仅文件传输会话不应用 PC 沉浸窗口偏好。
6. 补充沉浸开关恢复和保存结果诊断，沿用用户诊断开关，不记录远端标识、服务器地址或输入内容。

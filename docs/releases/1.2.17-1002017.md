# StarRustDesk 1.2.17（1002017）

## 更新内容

1. “键 → 更多”新增 ←、↑、↓、→ 四个方向按钮，可配合选中的 Ctrl、Shift、Alt、Win/Cmd 使用；点击不主动弹出软键盘，长按可调整顺序，保留已有自定义排序。

4. 增加方向键与输入法状态的脱敏诊断记录，不记录输入文字、密码或候选内容。升级首次启动弹窗及设置中的更新日志已同步更新。

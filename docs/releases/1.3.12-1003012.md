# StarRustDesk 1.3.12（1003012）

发布日期：2026-10-27。Git 标签：`v1.3.12-1003012`。

## 更新内容

1. 优化鼠标模式下轻点后再次按住移动的拖拽识别，减少被识别为右键的情况，保留双击与长按右键。
2. 手势指南采用图文卡片，涵盖鼠标、触摸、虚拟鼠标、投屏、键盘及其他操作说明；查看其他模式不改变当前控制模式。
3. 增加拖拽识别和长按来源诊断，遵循诊断开关，不记录输入文字或画面内容。

## 验证范围

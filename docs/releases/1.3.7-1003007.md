# StarRustDesk 1.3.7（1003007）

发布日期：2026-10-21。Git 标签：`v1.3.7-1003007`。

## 更新内容

1. 修复系统滚轮轴值被当作大量滚动档位的问题：鼠标、触控板、触屏与虚拟滚轮分别换算，增加单次输出及突发事件限制，丢弃过大的整数积压，减少滚动或缩放跳到两端的情况。
2. 虚拟滚轮上下按钮改为单档步进，保留滑动和中键点击；输入来源、设备、会话切换及手势取消时清理余量，保留横向滚动和用户主动按住的 Ctrl 等修饰键。
3. 增加滚轮来源、工具类型、系统轴值、发送档位及限幅次数诊断，物理滚轮诊断按秒采样，不记录设备名称或原始设备标识。
4. 增加音频收包、解码、播放回调、缓冲不足、队列丢弃、静音、系统中断和错误计数，定期汇总并在导出与停止时记录；实时播放回调只更新计数，不直接写日志，不记录声音内容。
5. 同步应用内简体中文、繁体中文及英文更新日志，首次展示标记更新为 `1.3.7-1003007`。

## 验证边界

- 滚轮测试覆盖日志中导致原 ±88/±89 档位跳变的大轴值、小数累积、方向反转、连续事件、输入来源和设备切换、异常数值及实际页面事件处理。
- 音频宿主测试编译实际播放器代码，以模拟平台与解码器覆盖收包、解码错误、缓冲不足、队列溢出、静音、系统中断、错误及播放器生命周期；不代表真实设备已恢复声音。
- 本轮尚未进行实机滚动或真实音频输出验收，无声问题仍需使用新日志复现定位；构建、签名及包解析不等同于应用市场审核通过。

# StarRustDesk 1.2.23（1002023）

发布日期：2026-10-07。Git 标签：`v1.2.23-1002023`。

## 本次更新

1. 按“配置的 ID 服务器地址 + 远端 ID / 直连地址”独立记住操控偏好：鼠标/触摸模式、光标显示、虚拟鼠标、边缘跟随、键鼠兼容；不同远端与不同服务器互不覆盖，未单独修改的项目继承旧默认值。
2. 按远端保存“控”和“键”的位置、排序、展开/折叠，以及更多按键顺序、PC 固定/自动收起状态、画面模式和缩放比例。位置使用相对坐标，窗口缩放、折叠、旋转及键盘变化后限制在可见区域。
3. 统一主功能栏：手机和平板横竖屏均为底部横向排列；PC 普通大小窗口和全屏均为顶部居中的横向悬浮栏，支持收为“控”，保留固定/自动收起、无边框窗口控制和独立退出全屏入口。
4. 键盘展开箭头改为同系列矢量图标，统一淡蓝选中背景、细分隔线与旋转动画；键盘按钮和组合键展开入口仍保持各自动作，点击箭头不主动弹出软键盘。
5. 偏好变更合并写入，拖动/捏合结束及离开远控时保存。白名单排除按键按住、鼠标按下、输入内容、全屏和当前菜单；补充脱敏恢复/保存诊断。
6. 原生配置读取改用完整 UTF-8 键，修复 IPv6 或较长服务器地址下独立偏好键超过 127 字节时被截断、重连后无法恢复的问题；不改动网络协议。

# StarRustDesk 1.1.0（1001006）

## 本次更新

- 手机远控功能栏改为半透明悬浮胶囊，支持拖动、收起和展开；平板及 PC 侧栏同步优化外观。
- 屏幕、鼠标、移动画面及边缘跟随等选中状态统一为淡蓝色，适配深色模式。
- 修复手机底部功能按钮显示不全，优化高度、间距和常用按钮宽度。
- 修复切屏后旧光标坐标反复隐藏鼠标的问题，改善 PC 多屏光标偶发消失，并增加诊断记录。
- 远控键盘快捷栏支持拖动，可收起为半透明小按钮，点击小按钮即可重新展开。
- 优化已保存连接的搜索布局，搜索框从按钮左侧展开，搜索、备份和分组按钮保持原位。
- 快捷栏发送 `Ctrl+Shift+Esc`、`Ctrl+Shift+Del`、`Alt+F4` 或 `Ctrl+Alt+Del` 后不再自动弹出本地软键盘。
- 补齐 F1–F12 物理功能键传递，修复控制 macOS 时 F3 无法送达远端的问题。
- 左右 Ctrl、Shift、Alt/Option 与 Meta/Command 分别按 RustDesk 协议传递，改善 `Ctrl+↑` 等组合键。
- 修复组合键重复附加修饰键和会话结束后修饰键残留的问题。
- 直连安全握手失败时保持加密并改走中继；注册服务器无响应或中继超时时进行有限次数的全新连接重试。

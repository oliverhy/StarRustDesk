# StarRustDesk 1.1.0（1001003）

## 本次更新

- 自建服务器密钥无效、格式错误或与服务器身份不匹配时，不再只显示笼统的安全握手失败。
- 新增明确的安全风险提示：可以取消连接，也可以由用户主动选择“仅本次继续”，临时使用未加密连接。
- 降级授权只对当前一次连接有效，不写入设置；断开连接或重新发起普通连接后自动恢复安全校验。
- 文件传输会话只在当前远控会话已获授权时沿用临时降级状态，避免重复失败或永久降低安全性。
- 补充服务器密钥异常、用户选择及临时降级流程的诊断记录和自动回归检查。

## 下载说明

Release 仅提供 **Release 构建的未签名 HAP**，需要使用自己的有效证书签名后安装。正式签名的 AppGallery `.app` 不上传 GitHub。

## 安全说明

“仅本次继续”会跳过远端身份验证，存在服务器被冒充或通信被窃听的风险。仅应在确认自建服务器地址可信、并了解风险时使用；推荐优先修正服务器公钥配置。

## 验证范围

- 118 项自动回归检查通过，覆盖服务器密钥错误识别、显式授权、单次有效和普通握手失败不降级。
- ARM64 / x86_64 原生库均包含本次安全连接逻辑。
- Release 未签名 HAP 已重新构建，包内版本为 `1.1.0（1001003）`，SHA-256 为 `0DCC323B0ED9EE4A47BB0D252CA36D4410E2379C3CF1AA46EDE09C2569CD95F2`。
- 以上不代替不同自建服务器版本和网络环境下的真机连接验收。

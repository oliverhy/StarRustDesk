# StarRustDesk 1.3.11（1003011）

发布日期：2026-10-26。Git 标签：`v1.3.11-1003011`。

## 更新内容

1. 新增触控屏三指左右滑动切换远端显示器，支持首尾循环；“控 → 屏幕 → 三指切屏”默认开启，按服务器与远端独立保存。
2. 新增 300 ms 横向滑动过渡：左滑时旧屏向左移出、新屏从右侧进入，右滑相反；功能栏保持原位，保留当前缩放比例。
3. 修复开发测试中切屏先闪一下、动画不播放的问题。旧画面就绪后才提交切屏，新画面准备完成后同步滑动；修正 ArkUI 图片对象包装造成的回调误判，不再依赖可能被持续视频推迟的空闲帧回调。
4. 完善三指方向判断、抬手去重、误触保护及过期回调隔离；保留双指滚动、捏合缩放和全屏三指上滑打开键盘。后台、断连、画中画或窗口变化会清理过渡；动画失败时恢复实时画面，不重复发送已受理的切屏请求。
5. 补充切屏识别、截图准备、图片加载、动画开始与结束、超时及取消阶段诊断。遵循已有诊断开关，不记录截图内容、密码或输入文字。
6. 同步应用内简体中文、繁体中文及英文更新日志，首次展示标记更新为 `1.3.11-1003011`。

## 验证范围与限制

- 动画回归覆盖无空闲回调、ArkUI 对象包装、旧回调、图片失败、超时、后台、窗口变化及重复操作；手势回归覆盖左右循环、方向冲突、关闭开关及偏好恢复。
- 同功能调试版已在鸿蒙平板实机完成两次左滑与两次右滑，四次均记录动画开始和结束；截图捕捉到横向滑动中间画面，测试后恢复原屏幕，未改动远端内容。
- 三指切屏适用于系统实际分发给应用的触控屏事件；不宣称支持被系统拦截的手势或未开放给应用的触控板三指事件。可继续使用“控 → 屏幕”按钮。
- 截图采样不等同于逐帧录像或所有机型验收；构建、签名及包解析不等同于应用市场审核通过。

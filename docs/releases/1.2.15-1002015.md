# StarRustDesk 1.2.15（1002015）

## 更新内容

1. 自建 ID 服务器未配置 API 账号时跳过不必要的账号会话准备；已记住账号或配置 API 时仍执行原有流程。
2. 在线状态查询只连接 ID 服务器辅助 TCP 端口，不再探测相邻 WebSocket 端口，减少与远控连接争用。
3. WebSocket 失败重试限定次数并共享超时期限，避免异常服务器导致重复尝试。
4. 鸿蒙 PC 远控使用沉浸式全屏；全屏时右侧功能栏收为右上角悬浮“控”按钮，同时保留独立的“退出全屏”按钮；退出后恢复固定侧栏。

# 芝麻远控 1.3.14（1003014）

## 更新内容

1. 修复等待远端连接响应时，已知 WebRTC 候选消息或空心跳先到可能导致连接提前报错的问题；继续在原有超时时间内等待有效响应。
2. 保持账号认证和加密校验；未知响应仍按错误处理，不自动降级为不安全连接。
3. 补充连接阶段、响应类型、处理结果和未知字段存在状态的诊断日志，不记录令牌、密码、候选内容或原始响应。

## 验证边界

已通过本地模拟服务测试覆盖旁路消息、真实响应、未知字段、加密连接、超时、消息数量限制与敏感信息保护。用户提供的旧日志未记录响应类型，因此尚不能确定其失败一定由该问题引起，仍需使用新包实机复测。

当前客户端使用非增量 WebRTC 协商；遇到不支持的增量候选消息会忽略该消息并继续等待连接结果，本次不包含完整 trickle ICE 支持。

## 本地发布验证

- 93 套应用回归及 81 项 Rust 测试通过，包括模拟账号认证、加密连接、旁路消息、未知响应、超时及诊断脱敏。
- 正式 APP 和内层 HAP 的签名、原生库代码签名及发布 profile 校验通过，证书链和 profile 与 1.3.13 完全一致。
- 官方 APP 的 ALL、HAP_LIST、HAP_INFO 及 HAP 解析通过；包内版本、双架构、图标、数据兼容标识及本次连接修复标记检查通过。
- 未使用用户账号或服务器进行端到端连接测试，也未安装设备；旧日志对应问题仍需用户复测确认。

## 发布方式

正式签名 APP 保留在本地供应用市场提交；本次仅提交并推送 GitHub 仓库，未创建 Release、安装设备或上传应用市场。

# 芝麻远控 2.0.7（2000007）

## 更新内容

1. 适配 RustDesk 1.5.3 可信设备 V2，同时保留旧版被控端的兼容；可信设备凭证仅在远端身份和加密通道通过验证后使用。
2. 修复通过二维码或剪贴板导入服务器配置后，当前页面输入框未立即刷新的问题；保存失败会明确提示。
3. 优化华为云恢复：空服务器字段保留本机值；备份与本机服务器不同且配置不完整时暂停恢复，避免混用服务器地址和 Key。
4. 恢复前暂存并校验密码，再整体提交连接、分组和服务器配置；发生写入失败或并发修改时不覆盖原有数据。
5. 完善云恢复结果提示及脱敏诊断，不记录密码、验证码、可信设备凭证、服务器密钥或输入内容。

## 使用及验证边界

- 可信设备 V2 需要远端允许可信设备、使用永久密码并启用二次验证；凭证保存在本机系统安全存储，不随云备份同步。是否可用取决于远端版本及配置。
- 未加密云备份默认不包含服务器 Key 或连接密码；空字段不会用于清空本机服务器设置，如需清空请在服务器设置中手动操作。
- 同一服务器的空地址字段会保留本机值；服务器不同且备份信息不完整时，需要先手动配置匹配服务器后再恢复。备份没有服务器信息时，应核对连接所属服务器。
- 为保证恢复失败时原密码不被覆盖，新恢复密码使用本机安全存储引用。覆盖降级到不支持该引用的旧版后，新恢复的密码可能不可见；原密码资产未主动删除。
- 此版本的云恢复和可信设备 V2 尚需实机、真实华为云及匹配被控端验证。签名构建不代表应用市场审核通过。
- 日志中 2.0.3 的远端首帧缺失和中继安全握手失败尚未确认根因，本次不声称该连接问题已解决。
- 包名、应用标识和正式签名保持不变。GitHub 沿用公开未签名 HAP 的发布方式；正式签名 APP 留在本地供应用市场提交。

构建、测试和签名核验结果见[发布核验记录](https://github.com/oliverhy/StarRustDesk/blob/v2.0.7-2000007/docs/releases/2.0.7-2000007-verification.md)。

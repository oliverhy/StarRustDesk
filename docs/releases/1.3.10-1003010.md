# StarRustDesk 1.3.10（1003010）

发布日期：2026-10-25。Git 标签：`v1.3.10-1003010`。

## 更新内容

1. 华为云空间最多保留最近 5 份有效备份；仅在新备份同步、校验及系统确认完成后清理更早版本，保留无关文件、临时文件和本地数据。
2. 云端备份清理增加库存复核、并发变化保护、部分失败处理及诊断；清理未确认时保持待处理状态并提示稍后重试，不把不完整清理误报为成功。
3. 修复新增和修改连接时“连接模式”下拉框不显示当前选项的问题，稳定、高帧率、高流畅、高丝滑及保留当前设置均可正确回显。
4. 远控二级菜单增加无文字、透明背景的上下滚动箭头；顶部仅显示向下提示，滚动后显示向上提示，到达边界后自动隐藏对应箭头。
5. 修复箭头提示层拦截滑动手势的问题，功能键及其他较长菜单恢复双向滚动；手机实机已验证功能键可在 F1 至 F12 之间往返滑动。
6. 同步应用内简体中文、繁体中文及英文更新日志，首次展示标记更新为 `1.3.10-1003010`。

## 验证范围

- 调试版已在手机完成保留数据的覆盖安装，并实机验证功能键菜单上下滑动及箭头边界状态；未对真实华为云端历史数据执行删除验收。

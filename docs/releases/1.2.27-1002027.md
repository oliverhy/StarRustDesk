# StarRustDesk 1.2.27（1002027）

发布日期：2026-10-10。Git 标签：`v1.2.27-1002027`。

## 本次更新

1. 新增自定义实体键盘映射，默认关闭。入口：远控 → 控 → 输入 → 手势说明 → 键鼠兼容 → 自定义键盘映射。支持选择或录入源按键、编辑目标、逐条启停、删除及恢复默认。
2. 首版支持左右 Ctrl、Shift、Alt/Option、Win/Command、F1–F12、方向及编辑键。修饰键只能映射为修饰键；普通功能键可映射到普通功能键或一次完整组合键。暂不提供字母/数字替换、任意源组合键重映射、CapsLock/Fn 重映射或宏脚本。
3. 新增 Mac 常用预设：Ctrl→Command（保留左右键）、Ctrl 与 Win/Cmd 互换、F3→Ctrl+↑。选择预设只替换草稿，不自动启用；保存后生效，取消不改变原配置。具体系统快捷键效果取决于远端设置。
4. 按服务器与远端设备独立保存和恢复，不同服务器上的同一 ID 互不覆盖。保存失败保留原配置，旧会话弹窗不能覆盖新设备；恢复默认在保存后关闭映射并清空规则。
5. 中文输入、输入法提交、粘贴、快捷栏按钮及现有完整组合键保持原路径。实体修饰键映射同步用于鼠标多选，保留左右按键及虚拟按钮的独立按住状态；去除原生/ArkUI 重复上报，切换配置、失去焦点或断开会话时释放旧按键。
6. 补充脱敏诊断，仅记录映射配置状态、按键代码与操作结果，不记录输入文字、密码或粘贴内容。编辑窗口打开失败不会留下远控输入锁定。

# 芝麻远控 2.0.9（2000009）

## 更新内容

1. 优化触摸鼠标位置同步：手指结束移动时补发最终位置，减少本地指针与远端悬停位置不一致。
2. 修复横竖屏切换或窗口尺寸变化后，鼠标箭头未按新画布比例及时更新的问题。
3. 优化远端光标样式和热点变化后的定位，保留原有点击、拖拽和实体鼠标操作。
4. 补充鼠标移动与光标重排的次数诊断，不新增输入内容或坐标记录。

## 使用及验证边界

- 鼠标位置同步和布局重算已通过代码级与模拟测试；用户反馈的具体设备、网络及截图场景仍需实机复验。
- 新增的指针诊断字段是次数统计；既有指针诊断字段在启用诊断时仍可能包含指针坐标。
- 本次不包含尚未确认具体界面的工具栏展开状态修改，也不声称其他未定位的连接问题已解决。
- 包名、应用标识和正式签名保持不变。GitHub 继续公开未签名 HAP；正式签名 APP 留在本地用于应用市场提交。

构建、测试和签名核验结果见[发布核验记录](https://github.com/oliverhy/StarRustDesk/blob/v2.0.9-2000009/docs/releases/2.0.9-2000009-verification.md)。

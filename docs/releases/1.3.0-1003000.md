# StarRustDesk 1.3.0（1003000）

发布日期：2026-10-14。Git 标签：v1.3.0-1003000。

## 本次更新

1. 统一重做远控“屏幕、输入、键盘、画面、更多、屏幕方向”六类子菜单，采用紧凑半透明面板、统一图标和淡蓝选中状态，减少遮挡并保留现有业务逻辑。
2. 子菜单跟随功能栏位置和可用空间智能向上或向下展开；统一打开、切换和关闭动效。菜单外部的透明拦截层只关闭菜单，不向远端发送误触输入。
3. 屏幕方向设置永久保存到本机：跟随系统开关以及自动、竖屏、横屏选择在重新进入远控和重启 App 后继续生效。应用单独投屏方向保持会话级，不覆盖手机或平板的独立选择。
4. 优化手机、平板、折叠屏和 PC 窗口的大字体、窄窗口及横竖屏布局；按实际文字宽度和字体比例计算菜单尺寸，修复方向说明被裁切、分页留白和菜单越界。
5. 鼠标、触摸和屏幕方向的选中状态统一为淡蓝高亮，不再显示勾号；完善深色模式、滚动区域、键盘快捷键分页和释放按键入口。
6. 保留屏幕切换、实体键鼠、组合键、软键盘、文件传输、录像、隐私模式、画中画和全屏等现有操作路径；方向切换退出远控时仍恢复原窗口方向。

## 更新说明与发布边界

- App 首次升级弹窗和设置更新日志同步更新，1.3.0 置顶；首次展示标记更新为 1.3.0-1003000。简体中文、繁体中文和英语同步更新。
- 本次不修改 Rust/C++ 网络协议、视频解码和正式签名身份。
- 已在 Mate60 Pro 真机核对菜单布局、方向说明完整显示、鼠标与触摸选中样式及方向菜单关闭后保留；自动化新进程测试覆盖方向设置在 App 重启后的恢复。
- GitHub Release 只提供未签名 Release HAP；正式签名 APP 留在本地用于华为应用市场上架，不上传 GitHub。

# StarRustDesk 1.3.8（1003008）

发布日期：2026-10-23。Git 标签：`v1.3.8-1003008`。

## 更新内容

1. 修复软键盘打开后只轻微上移、下方输入位置仍被遮挡的问题。优先使用最近一次实际发送到远端的点击位置；没有有效定位时按当前可见画面下沿避让，不再将画面中心当作输入位置。
2. 保持键盘打开前的画面比例与缩放，仅临时向上移动；关闭键盘后恢复原位置。改善连续开合、已放大画面以及不同键盘高度下的行为。
3. 键盘打开时支持通过“移动画面”手动调整可见区域；切换远端、显示器或分辨率时清除旧定位，修正上移后的触摸坐标，并保护按下、松开之间的点击位置一致性。
4. 增加避让来源、原因、定位时效、遮挡高度、可见高度、上移距离及手动调整状态诊断；由原有诊断开关控制，不记录输入文字、密码或声音内容。
5. 更新应用内简体中文、繁体中文及英文更新日志，首次展示标记更新为 `1.3.8-1003008`。

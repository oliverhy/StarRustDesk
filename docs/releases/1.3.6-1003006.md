# StarRustDesk 1.3.6（1003006）

发布日期：2026-10-21。Git 标签：`v1.3.6-1003006`。

## 更新内容

1. 修复画面菜单“＋／−”显示为小点：使用独立 SVG 图标，适配屏幕密度和深浅色主题，保持紧凑布局。
2. 缩放按钮按 25% 标准档位增减，不再沿用双指缩放的小数余量；121% 缩小到 100%，96% 放大到 100%，保留手机 50%–500% 和 PC 25%–300% 的范围。
3. 点击中间百分比一键恢复 100% 并居中，即使当前已是 100% 也能重新居中。手机和平板的 100% 是初始适应画面比例；PC 的 100% 保持远端像素与本地物理像素对应。
4. 复位结果按远端独立保存，清理未结束的平移和缩放手势、更新虚拟鼠标；页面退出、断线、菜单关闭动画和画中画持有画面时不接受过期操作。
5. 保留 1.3.5 修订 r2 的键盘等比例上移避让、横屏键盘按钮靠右、功能键栏独立收放及底部白边修复。

## 更新说明与发布

- 应用内更新日志置顶，首次展示标记为 `1.3.6-1003006`，同步简体中文、繁体中文及英文。

## 实机验证边界

- 本轮缩放调试包已在目标设备覆盖安装，SVG 图标经截图确认；实测标准档位增减、从 150% 点击复位为 100%、从 100% 减至 75% 再加至 100%，画面恢复居中，用户确认无问题。
- 自动化覆盖任意双指缩放比例到标准档位、浮点边界、缩放范围、复位与保存、PC 比例含义、页面生命周期和画中画保护。
- 调试包实机验证不等同于所有手机、折叠屏、平板和 PC 的验收；构建和签名检查不代表应用市场审核结果。

# 2.0.1（2000001）发布核验

- 正式 release APP 的外层签名、内部 HAP 签名及 release profile 验证通过；与 2.0.0 的证书和 profile 一致，APP 内 HAP 与单独验证的 HAP 字节一致。
- 核对 APP 和 HAP 版本、包名、非调试标记、ARM64 与 x86_64、图标、扩展屏 Ability、局域网功能及存储兼容标识；13 项签名与数据相关保护文件未改变。
- 官方解析器的 APP `ALL`、`HAP_LIST`、`HAP_INFO` 和 HAP 解析通过。
- 全部 117 组 JavaScript/组件回归通过；Rust 主机测试以 `cargo test --locked --offline --lib -- --test-threads=1` 运行，113/113 项通过。两项旧测试的静态断言已更新，以匹配弹窗状态共享和新增页面清理步骤，原有行为检查保留。
- 横屏密码弹窗及未加密提示取消流程已在 192.168.2.66 的调试版上实测；仅使用未保存的临时密码，未登录或修改远端。局域网发现已与官方 RustDesk 客户端联测。
- 扩展屏全屏逻辑通过自动测试，但本次尚未在鸿蒙 PC 扩展屏上实机验收；测试和签名验证不代表应用市场上传或审核通过。

# StarRustDesk 1.3.0（1003000）修订 r1

发布日期：2026-10-14。Git 标签：`v1.3.0-1003000-r1`。App 版本名、版本代码和 buildVersion 均保持原值。

## 本次修订

1. 键盘子菜单的“修饰键、功能键、更多按键”固定在最底部，切换分页时中间按键区域继续可滚动。
2. “释放按键”移到右上角，与“键盘”标题齐平；字号为 11 fp，窄窗口下可自适应到 10 fp，保留原有释放按键功能。
3. 去除原底部释放行的高度预留，菜单更加紧凑；手机调试包已安装并由用户确认布局效果正常。
4. 本次说明并入 App 的 1.3.0 更新日志，简体中文、繁体中文和英语同步更新；首次展示标记更新为 `1.3.0-1003000-r1`。

本版本包含 [1.3.0 首次发布](https://github.com/oliverhy/StarRustDesk/releases/tag/v1.3.0-1003000) 的六类远控子菜单、持久化方向设置、自适应布局和选中状态修复。

# 芝麻远控 2.0.4（2000004）

## 更新内容

1. 新增“提交后收起键盘”选项，默认关闭并按远端设备分别保存；开启后按输入法提交键会发送回车并收起键盘，关闭时保留连续输入方式。
2. 优化中文输入法组词与提交顺序，等待候选内容确认后再处理提交，减少输入中途收起键盘的情况。
3. 安全清理应用的临时输入缓存，防止输入法清空隐藏输入框时误向远端发送大量退格，并过滤过期输入回调；不会清理系统输入法词库。
4. 完善键盘提交与收起状态诊断，不记录密码、输入文字或输入法候选内容。

## 使用及兼容性说明

- 远控后可在“控 → 输入 → 键盘设置”中启用“提交后收起键盘”。该选项响应输入法提交键，不代表应用能够识别远端登录成功。
- 不修改包名、应用标识、签名、现有连接、密码或备份格式；正式包的安装升级仍需实机验证。
- 中文组词、提交顺序、连续输入与缓存清理已做自动化测试；不同鸿蒙设备与输入法仍需实机验证。
- GitHub 沿用公开未签名 HAP 发布方式，需自行签名安装；正式签名 APP 留在本地供应用市场提交，不代表已通过应用市场审核。

构建、测试及签名核验结果见 [发布核验记录](2.0.4-2000004-verification.md)。

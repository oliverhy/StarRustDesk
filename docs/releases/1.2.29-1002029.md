# StarRustDesk 1.2.29（1002029）

发布日期：2026-10-12。Git 标签：`v1.2.29-1002029`。

## 本次更新

1. 首页快捷连接与保存连接分离：已保存连接右侧“＋”用于新增，设备“更多 → 修改”使用独立编辑弹窗。修改时远端 ID 固定，重复连接不覆盖旧记录；取消不改变首页输入。
2. 完善保存校验、失败回滚、过期编辑和服务器切换保护；新设备不继承旧设备密码、系统密码或安全设置。备份、云同步保留可选网络标识，兼容旧连接记录。
3. 精简列表仅显示备注名称，无备注时显示 ID。缩小连接按钮、标题按钮、展开折叠图标及行高，优化设备数量间距；保留足够点击范围，大字体或窄窗口下自适应。
4. 连接选项默认折叠，远端 ID / IP 输入框始终可见；标准字体下输入框高度由 62 调整为 48，箭头按钮同步缩小。连接模式使用紧凑下拉菜单，保留自定义码率、帧率和展开折叠动效。
5. 排序、列表显示方式、语言、按钮样式及文件排序菜单的勾选标记统一放到文字后面。移除设置页“账户 / 设备名称”栏目，服务器账号、API 登录与地址簿功能保持不变。

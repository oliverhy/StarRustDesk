# StarRustDesk 1.1.0（1001005）

## 本次更新

- 修复 HarmonyOS 6 平板使用蓝牙或 USB 外接键盘控制 Ubuntu/KDE 时，`Q/W` 等按键错误变成数字键的问题。
- 物理键盘改为传递通用 USB HID 位置码，并根据被控端系统转换为 Windows、Linux、macOS 或 Android 对应键码。
- Linux 被控端使用正确的 Xorg/XKB 键码；Windows 原有扫描码行为保持不变。
- 同步覆盖数字、标点、Shift 大小写、按键释放和会话重置处理。

## 验证范围

- HarmonyOS 键码到 USB HID 的自动映射检查通过。
- Windows、Linux、macOS 和 Android 目标键码自动回归检查通过。
- 原有 Shift 数字行、输入事件队列及其他项目回归检查通过。
- 正式 AppGallery `.app` 的签名和完整性验证结果见构建产物。

自动检查不能代替在 HarmonyOS 6 平板、雷柏蓝牙键盘和 Ubuntu 24.04 KDE 环境中的真实输入验收。

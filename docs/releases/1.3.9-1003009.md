# StarRustDesk 1.3.9（1003009）

发布日期：2026-10-24。Git 标签：`v1.3.9-1003009`。

## 更新内容

1. 新增“域名＋端口”直连支持：显式 `host:port` 通过 DNS 与双栈候选连接，覆盖远控及文件传输会话；保留 IPv4、IPv6、自定义端口和未指定端口的自定义 ID 行为。非法地址不发送给 ID 服务器，直连不会作为安全校验失败后的自动降级。
2. 优化电脑模式全屏：结合设备类型、自由窗口能力和实际窗口状态进入沉浸全屏，控制标题栏与任务栏悬停显示，验证结果并在失败时回滚；退出后恢复原窗口状态。
3. 修复本地 2FA 输入：验证码框优先接收键盘事件，进入验证时清理旧菜单与远控输入状态，请求本地焦点并支持回车提交；同步优化 API 账号验证码框。
4. 外观支持“跟随系统／浅色／深色”，统一管理状态栏和导航栏；远控使用深色背景，退出时恢复当前主题，避免旧会话、系统主题变化或异步回调恢复过期颜色。
5. 修复鼠标双击误过滤：使用事件来源、位置、时间戳和按下／松开序列识别重复投递，保留真实第二击；改进点击补发保护，兼容点击事件使用按下或松开时间戳的情况。
6. 补充连接阶段与耗时、全屏请求与实际状态、2FA 焦点及提交结果、系统栏主题、鼠标点击间隔与去重依据诊断；新增日志不记录验证码、密码或输入文字。
7. 同步应用内简体中文、繁体中文及英文更新日志，首次展示标记更新为 `1.3.9-1003009`。

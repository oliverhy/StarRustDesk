# StarRustDesk 1.1.0（1001002）

## 本次更新

- 修复多指滚动、缩放、三指手势结束后误触右键；保留双指轻点右键，取消手势不再触发点击。
- 修复鸿蒙 PC 键鼠事件顺序与 Ctrl/Shift 多选；分别跟踪左右修饰键，正确释放按键，保留普通字母的远端输入法路径。
- 新增 IPv4/IPv6 地址直连及指定端口，远控与文件会话均可绕过 ID 服务器；未加密连接显示提醒。
- 修正公共服务器默认地址与公钥配置，保留自建服务器配置；远控密码不作为服务器访问令牌发送。
- 完善连接总超时、取消、快速重连和双栈 Wi-Fi 中继回退；限制文件会话建立及在线查询的等待时间。
- 修复在线查询迟到结果、长期黄灯及无效结果处理；IP 地址显示独立的状态未知提示。
- 改进后台保活兼容性：视频子模式被拒绝后依次尝试普通多设备互联和兼容接口；完善取消、暂停、恢复、失败重试与真实状态记录。
- 已保存连接新增 ID、名称、在线状态排序，并记住选择。
- 完善首帧和解码恢复、横竖屏画面重绑定、按会话重置的视频统计及安全握手校验。
- 诊断日志增加手势判定、键鼠队列顺序、连接阶段、版本及原生构建标识。应用更新后首次启动弹窗与设置内更新日志同步更新，最新内容在前。

## 下载说明

Release 仅提供 **Release 构建的未签名 HAP**，需要使用自己的有效证书签名后安装。正式签名的 AppGallery `.app` 仅供作者提交华为应用市场，不上传 GitHub。IP 直连需要远端开启直接 IP 访问，并应仅在可信网络使用。

# 芝麻远控 2.0.11（2000011）

## 更新内容

1. 修复普通鼠标的默认箭头尖端偏移；在缩放和横竖屏变化后，绘制位置与实际点击目标保持一致。
2. 优化普通鼠标的位置同步：短滑停手补发最终位置，点击或拖拽前先同步目标，减少悬停和点击错位。
3. 优化触摸滑动判定，减少轻扫或慢速起步时误触发左键或右键，保留正常点击、双击、长按和拖拽。
4. “控”贴边后仍为窄条，调整为与展开栏等高，随字体大小适配，保留两次点击的展开方式。
5. 完善鼠标诊断，区分本地排队结果和远端光标反馈；此次新增字段不记录原始坐标、键盘输入或剪贴板内容。排队成功不代表远端已执行。

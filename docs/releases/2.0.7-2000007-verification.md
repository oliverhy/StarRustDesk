# 2.0.7（2000007）发布核验

- Release HAP 与 APP 构建成功；APP 和内含 HAP 的包名均为 `com.yinhe.starrustdesk`，版本均为 `2.0.7 / 2000007`，HAP 为 `debug=false`、`buildMode=release`。构建有 SDK 兼容性及弃用 API 警告。
- APP 外层与内含 HAP 的正式签名、完整性和发布描述文件均经工具验证；证书链与描述文件和 2.0.6 一致，发布类型为 `release / app_gallery`。APP 内 HAP 与单独签名 HAP 字节一致。
- ARM64 与 x86_64 Rust 核心 Release 构建成功，链接用静态库与对应架构产物的 SHA-256 一致；HAP 内两个 ELF 架构、应用图标及存储格式标识核验通过。
- 147 项 Rust 单元测试通过；22 组发布相关脚本测试通过，另有 76 组云同步运行时场景通过，覆盖服务器配置恢复、冲突、回滚、并发修改和脱敏日志。

- 日志中的远端首帧缺失和中继安全握手失败尚未确认根因，本次不声称该连接问题已解决。

# StarRustDesk 1.3.2（1003002）

发布日期：2026-10-17。Git 标签：`v1.3.2-1003002`。

## 本次更新

1. 统一本地和投屏窗口中实体鼠标按键的跨通路去重，处理原生鼠标、ArkUI 鼠标及鼠标兼容触摸事件的重复投递，修正每次点击多发一次“松开”的异常。
2. 普通实体鼠标和触控板单击、双击不再误显示“左键按住”；触屏模拟拖拽和虚拟鼠标拖拽继续保留提示。
3. 补齐不携带坐标的松开事件去重，并统一触摸模式下兼容输入与鼠标输入的画面坐标；保留真正的快速连续点击、左右键、拖拽和漏事件点击补偿。
4. 增加按键事件被去重时的诊断，沿用用户诊断开关，不记录输入文字、密码或剪贴板内容。

## 更新说明与发布

- App 首次升级弹窗及设置更新日志添加 1.3.2 并置顶；首次展示标记为 `1.3.2-1003002`。简体中文、繁体中文和英语同步更新。
- GitHub Release 只提供未签名 Release HAP；正式签名 APP 保存在本地用于华为应用市场上架。

## 验证边界

- 本次增加 18 项检查，覆盖诊断日志顺序回放、快速双击、反向到达顺序、无坐标松开、多通路混合输入、触控板兼容输入、坐标一致性和拖拽提示。
- 修复前，日志回放输出为“按下、松开、松开、按下、松开、松开”；修复后为两组正常的“按下、松开”。
- 自动化测试与编译不替代真机验收：资源管理器双击打开文件夹、真实左右键和拖拽仍待用户设备验证。

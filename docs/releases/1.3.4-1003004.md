# StarRustDesk 1.3.4（1003004）

发布日期：2026-10-18。Git 标签：`v1.3.4-1003004`。

## 本次更新

1. 修复上传完成确认被误当成下载回复，导致“0 字节、等待数据”一直不结束的问题。上传和下载按任务编号分流，迟到、重复及取消后的回复不再改写其他传输状态。
2. 上传数据发完后显示“等待远端确认”，收到对应任务的完成确认后才报告成功并清理本地临时文件；保留小文件、空文件、覆盖上传和连续上传的正确进度。
3. 增加等待确认超时、传输停滞和连接中断处理。等待远端完成确认超过 30 秒，或数据传输 60 秒没有进展时结束任务并说明原因；确认超时会提示文件可能已送达，避免直接重试造成重复传输。
4. 完善取消、批量下载及连接退出的任务收尾。诊断日志记录任务编号、方向、字节数、确认阶段、停滞时长和失败分类；仍由诊断开关控制，不在新增日志中记录文件内容、密码或完整路径。

# 芝麻远控 2.0.8（2000008）

## 更新内容

1. 优化远控“控”悬浮按钮：折叠后可拖动到左右边缘，吸附时显示低调的贴边细条。
2. 吸附细条点一次恢复“控”，再点一次展开控制栏；可再次拖动吸附，并记住各远端的按钮位置。
3. 安卓被控端的“手机操作”悬浮条显示状态按远端独立保存；重新连接同一设备时恢复上次选择，主动关闭后保持关闭。
4. 完善“手机操作”状态保存失败提示与脱敏诊断；恢复悬浮条不会自动发送返回、主页、电源等远端操作。
5. 优化贴边控件在不同窗口尺寸下的布局及虚拟手柄避让。

## 使用及验证边界

- 只有将折叠的“控”手动拖到边缘才进入吸附；点细条后恢复普通“控”按钮，再次拖动可重新吸附。按钮位置按远端保存，重新连接后不会自动进入吸附状态。
- “手机操作”仅在识别为安卓的被控端上显示；首次使用需手动开启。自动恢复只影响本地悬浮条，不会发送远端按键。
- 用户反馈当前交互可以；本次版本的安卓被控端“手机操作”状态恢复尚需实机联测。自动测试和构建成功不代表应用市场审核通过。
- 之前日志中的远端首帧缺失和中继安全握手失败尚未确认根因，本次不声称该连接问题已解决。
- 包名、应用标识和正式签名保持不变。GitHub 继续公开未签名 HAP；正式签名 APP 保留在本地供应用市场提交。

构建、测试和签名核验结果见[发布核验记录](https://github.com/oliverhy/StarRustDesk/blob/v2.0.8-2000008/docs/releases/2.0.8-2000008-verification.md)。

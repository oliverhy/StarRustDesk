# StarRustDesk 1.3.5（1003005）

发布日期：2026-10-21，修订 r2（版本号不变）。Git 标签：`v1.3.5-1003005`。

## 修订 r2

1. 修复软键盘遮挡远端输入位置：保留原画面比例、缩放及用户平移设置，仅将画面向上移动，关闭键盘后恢复；覆盖手机、平板、折叠屏及键盘高度变化，PC 保持原有处理。
2. 横屏独立键盘悬浮按钮默认靠右、继续支持拖动，键盘弹出后限制在可见区域内。
3. 软键盘与左侧修饰键、功能键栏独立收放；键盘开合、横竖屏变化不再自动展开按键栏，保留已保存的状态。
4. 远控底部系统手势区使用深色背景，消除横屏白边；不禁用导航手势，不扩大远端画布或控件的布局范围，离开远控恢复原导航栏样式。
5. 增加键盘高度、可见区域、上移量、缩放和按键栏状态诊断；不记录输入内容、密码或令牌。
6. 保持 `1.3.5 / 1003005`，更新说明展示标记为 `1.3.5-1003005-r2`。

## 修订 r1

1. 修复虚拟鼠标滚轮箭头错位：上下箭头和中键使用独立固定区域及 SVG 图标，不再被文字适配撑高，不与下方“移动”区域重叠；中键三条线在不同屏幕密度下保持清晰，左右键恢复独立尺寸。
2. 手机和平板上，“控”展开或折叠时均保留独立键盘悬浮按钮，拖动及键盘开关功能不变；设置、聊天等弹层及文件传输模式的隐藏规则不变。
3. 保持 `1.3.5 / 1003005`，更新说明展示标记改为 `1.3.5-1003005-r1`，升级修订包后可展示一次新增说明。

## 本次更新

1. 已登录会话遇到传输中断、Windows 登录切换期间临时离线或连接超时，可在约 30 秒窗口内按退避间隔尝试自动重连；重连成功后重置恢复预算。首次连接未成功、认证失败、远端主动结束、账号或服务器变化不走该恢复流程，也不会自动降级为未加密连接。
2. 修复失败页“重试”错误退出远控，改为在当前页面重新连接；支持取消重连，防止离开页面后旧异步任务重新建立连接，单次未加密授权不自动复用。
3. 活动连接点击断开或返回退出时先弹窗确认；菜单、软键盘和全屏优先收起。明确取消重连以及已经失败的连接返回时不重复确认。
4. 调整已保存连接工具栏为搜索、分组、备份顺序；展开搜索框与管理按钮协调对齐，提高搜索框高度，保持窄窗口和大字体下的自适应。
5. 统一改善操作按钮、说明文字及长名称显示。按钮标签优先完整显示、说明自动换行，长连接名称可查看和复制完整内容；保留手机、平板、折叠屏、PC 以及深浅色和按钮样式适配。
6. 完善重连原因、退避等待、尝试次数、取消及退出确认诊断。远端结束原因只导出固定分类，不记录原始关闭文本、密码、令牌或输入内容。

# StarRustDesk 1.2.21（1002021）

同版本最新修订见 [1.2.21 修订版 r2](1.2.21-1002021-r2.md)，补充地址簿 IP 设备兼容、分页同步保护和全选修复；此前独立键盘按钮、连续输入及投屏鼠标接收优化见 [修订版 r1](1.2.21-1002021-r1.md)。以下为首发记录。

## 更新内容

1. 修复应用忽略系统旋转锁定的问题。手机和平板默认跟随系统旋转设置，首页、远控及退出远控后不再恢复为忽略锁定的自动旋转模式。
2. “控”中的屏幕方向按钮新增选择菜单：跟随系统、固定竖屏、固定横屏。手动选择仅对本次远控生效，结束后恢复默认策略。
3. 单独投屏的方向选择与手机本屏分离。外接横向屏幕仍自动适配横屏，也可手动固定方向；返回本屏后恢复本屏选择，不改变远端分辨率。
4. 更新手势说明、繁体中文与英语文字，增加脱敏方向诊断。关闭菜单、离开页面或切换显示设备时不误应用旧菜单选择。

## 发布信息与验证边界

- 包名：`com.yinhe.starrustdesk`；版本：`1.2.21（1002021）`。
- GitHub Release 仅提供未签名 Release HAP，需要自行签名后安装；正式签名 APP 留在本地用于 AppGallery 上架。
- 自动化检查覆盖方向模式、投屏切换与返回、菜单取消、窗口异常、PC 隔离以及既有键盘避让和全屏逻辑。实际系统旋转锁定、折叠屏和单独投屏效果仍需真机验收。
- Ubuntu 登录界面到桌面切换后的黑屏/停帧问题尚未在本版本修复；此前实验性 HDR 的设备与视频源限制仍适用。
- 构建和签名验证不代表已通过应用市场审核或全部真机验收。

- 49 项 Node 回归检查、55 项 Rust 单元测试全部通过。
- ARM64 与 x86_64 Rust Release 库构建通过；Release APP 构建成功。
- 正式 APP 内层 HAP、外层 APP 签名及完整性验证通过，发布证书配置为 `release / app_gallery`。
- APP 与 HAP 的包名、版本名、版本代码均已核对；HAP 为 `buildMode=release`、`debug=false`，默认方向为 `auto_rotation_restricted`。

# 芝麻远控 2.0.2（2000002）

## 更新内容

1. 重新设计游戏悬浮控制台，统一远控功能栏风格，快速切换虚拟手柄、屏幕按键和相对鼠标，支持按键编辑与灵敏度调整。
2. 修复未配置过的游戏方案缺少默认屏幕按键的问题，提供方向、鼠标及空格键预设；已有自定义或空方案不会被覆盖，空方案可手动加载预设。
3. 虚拟手柄与屏幕按键同时开启时自动避让，尽量保持方向键组合排列；关闭手柄后恢复原位置，不改写已保存的方案。
4. 悬浮键盘和“控”栏自动避让手柄与屏幕按键，支持拖动、展开和折叠；屏幕空间不足时提示并暂时隐藏手柄，避免遮挡误触。
5. 完善屏幕按键编辑、取消和按键释放处理，补充不含密码、令牌或输入内容的布局诊断。

## 兼容性与验证边界

- 保持应用包名、正式签名身份与既有连接、密码、设置及备份格式不变，无需卸载升级。
- 虚拟手柄为键盘和鼠标映射，并非原生游戏手柄透传；对游戏内实际响应的效果取决于被控端和游戏。
- 平板调试包已验证控件同时显示、自动避让、关闭后恢复、编辑取消、“控”栏展开折叠、菜单以及软键盘开合；为保护远端内容，未测试实际游戏按键。
- 小窗口避让和空间不足的处理已做自动测试，尚未覆盖所有鸿蒙设备和屏幕尺寸。
- GitHub 沿用公开未签名 HAP 发布方式，需自行签名安装；正式签名 APP 供应用市场提交，不代表已通过市场审核。

发布前 122 组功能回归和 113 项 Rust 核心测试通过，正式签名及包内容核验通过；详见 [发布核验记录](2.0.2-2000002-verification.md)。

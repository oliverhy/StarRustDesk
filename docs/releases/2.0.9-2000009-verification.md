# 2.0.9（2000009）发布核验

- Release HAP 和 APP 构建成功；APP 与内含 HAP 的包名均为 `com.yinhe.starrustdesk`，版本均为 `2.0.9 / 2000009`，HAP 为 `debug=false`、`buildMode=release`。构建存在 SDK 兼容性与弃用 API 警告。
- APP 外层与内含 HAP 的正式签名、完整性和发布描述文件均经工具验证；证书链及描述文件与 2.0.8 一致，发布类型为 `release / app_gallery`。APP 内 HAP 与单独签名 HAP 字节一致。

- 15 个相关脚本测试通过，覆盖末次触摸移动补发、拖拽释放顺序、实体鼠标、多指手势、横竖屏光标重算、键盘避让、远端偏好、版本和多语言。

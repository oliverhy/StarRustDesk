# 芝麻远控 2.0.5（2000005）

## 更新内容

1. 修复重复复制相同文字或发送失败后不再重试的问题，改善鸿蒙 PC 向 Mac 远控时文字同步不稳定的情况。
2. 优化远端文字写入、本地读取和窗口焦点切换的处理，减少双向同步过程中的状态冲突。
3. 新增主动同步本机文字入口：在“控 → 输入”中使用系统粘贴按钮授权，适用于系统限制自动读取剪贴板的情况。
4. 完善剪贴板同步状态诊断，不记录剪贴板文字；当前同步支持文字，不代表支持图片或文件剪贴板。

## 使用及兼容性说明

- 在本机复制后，打开“控 → 输入”，开启剪贴板同步；如系统限制自动读取，点击“同步本机文字到远端”下的系统粘贴按钮，然后在远端执行粘贴。入队成功不代表远端已确认接收。
- 不新增系统受限剪贴板权限，不改变包名、应用标识、签名或已保存连接、密码、设置和备份数据格式。
- 剪贴板文本同步和诊断脱敏已做自动化测试；受鸿蒙系统授权、远端协议与设备环境影响，鸿蒙 PC 与 Mac 的真实复制粘贴行为仍需实机验证。
- 此版本未改变服务器或降低连接安全性；提交应用市场后仍需等待平台审核。

构建、测试及签名核验结果见[发布核验记录](2.0.5-2000005-verification.md)。

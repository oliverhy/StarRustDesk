# 2.0.6（2000006）发布核验

- Release HAP 和 APP 构建通过。APP 外层与内部 HAP 均校验为 `com.yinhe.starrustdesk`、`2.0.6 / 2000006`；内部 HAP 为 `debug=false`、`buildMode=release`。
- APP 和 HAP 的正式签名、完整性和发布描述文件通过工具校验；内外证书链与描述文件均与 2.0.5 一致，描述文件为 `release / app_gallery`。APP 中 HAP 与单独签名 HAP 的哈希一致。
- 包含 ARM64 与 x86_64 ELF 原生库；链接静态库的哈希分别与本地对应架构的 Release 构建产物一致。包内应用图标与工程原始图标字节一致。
- 123 组 JavaScript／组件回归通过（包含多行输入、中文组合、手动回车、连接重试、安全和脱敏检查）；其中退出会话测试因新状态缺少测试桩字段而初次失败，补齐测试桩并增加待处理输入保护用例后通过。另有 HDR 视频与 PC 会话冻结两组未运行，以避免覆盖已有测试产物。
- 136 项 Rust 核心测试通过，包含中继、重试、身份校验、加密和诊断脱敏等检查。
- 此包尚未进行手机或被控端实机验收。微信输入法语音分段的回调顺序与 Windows、macOS、Linux 被控端的实际粘贴行为仍需验证；构建与签名成功不代表应用市场审核通过。
- 此前手机移动数据下连接目标服务器仍有失败，当前服务器或中继问题尚未确认解决，本次不应声称已彻底修复。

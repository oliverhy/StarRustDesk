# StarRustDesk 1.1.0（1001007）

## 新增与优化

- 连接页与设置页统一柔和卡片、悬浮导航和淡蓝色选中风格，适配深色模式。
- 上方快捷栏默认折叠为“键”，底部工具栏可折叠为“控”；统一尺寸、透明度、收起按钮与伸缩过渡。
- 修复修饰键选中状态刷新；折叠后保留按键状态，并用小蓝点提醒。新增“释放”按钮，不影响本地键盘开关。
- 底部“鼠标 / 触摸”采用居中纯文字，补齐手势与组合键使用说明。
- 取回文件支持名称、类型（扩展名）、大小、修改时间排序及升降序切换；文件夹优先，数字名称自然排序，保留已选文件。
- 优化长文件名与详细信息显示，增加项目计数和空目录提示。

## 连接与后台任务修复

- 修复直连安全握手失败后路线信息丢失，导致未触发加密中继重试的问题；不会自动降级为未加密连接。
- 完善后台任务错误码兼容与回退判断，增加连接路线、登录失败分类及后台任务诊断信息。

更新后首次启动将显示本次更新内容，设置中的更新日志同步更新，最新版本在最上方。

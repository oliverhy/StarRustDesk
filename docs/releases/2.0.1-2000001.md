# 芝麻远控 2.0.1（2000001）

## 更新内容

1. 新增局域网设备发现，兼容官方 RustDesk 的发现协议，无需修改服务器；支持通过设备 ID 连接，或在远端开启直接 IP 访问时选择 IP 直连。
2. 加强局域网连接安全：发现设备不代表已验证身份，发现设备不会自动复用已保存密码；未加密连接仍需用户单独确认。
3. 鸿蒙 PC 扩展屏新增全屏及退出全屏入口，切换时释放按键并调整画面布局；是否可用取决于系统和设备。
4. 修复横屏输入连接密码时键盘及底部导航栏遮挡操作按钮的问题；取消未加密连接提示后直接返回首页。
5. 补充局域网发现和连接安全诊断，不记录密码、令牌或原始响应。

## 兼容性与验证边界

- 原包名、签名身份与连接、密码、设置和云备份格式保持不变，无需卸载升级。
- 官方 RustDesk 的局域网发现及密码窗口、未加密提示取消流程已在平板调试版上验证；未执行真实密码登录，也未修改远端内容。
- 扩展屏全屏逻辑通过自动检查，具体效果仍需在对应鸿蒙 PC 和扩展屏设备上验证。
- 直连依赖远端设置及网络条件；发现的设备身份需用户自行核实。公开的 GitHub HAP 未签名，需自行签名安装；正式签名 APP 用于应用市场提交。

发布前 117 组功能回归及 113 项 Rust 核心测试通过，正式签名与包内容核验通过；详见 [发布核验记录](2.0.1-2000001-verification.md)。

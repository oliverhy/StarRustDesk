# 芝麻远控 2.0.3（2000003）

## 更新内容

1. 优化实体键盘识别与 Mac 键盘布局校准；多把键盘可分别校准，同一键盘被系统识别为多个输入设备时可经确认一起校准。
2. 首次连接跟随远端默认屏幕，同一会话重连时尽量恢复之前选择的屏幕，改善部分多屏设备在锁屏或登录阶段黑屏的问题。
3. 完善主屏及扩展屏键盘来源识别、按键释放和异常处理，保留软键盘、中文输入以及现有自定义快捷键设置。
4. 键盘诊断不记录按键内容或扫描码，应用内旧诊断日志重新导出时会再次脱敏，并补充选屏与键盘校准状态诊断。

## 使用及兼容性说明

- 连接 Mac 后，在“控 → 输入 → 键盘设置”选择“苹果布局修正”，使用目标实体键盘校准 Command / Option。系统无法稳定识别键盘时，校准仅在当前设备清单有效期内生效。
- 保持应用包名、签名身份和既有连接、密码、设置及备份格式；本次不需要卸载或迁移数据。
- 新版重新导出时会对应用内历史日志脱敏，但已经导出到其他位置的旧日志不会被自动修改；旧文件可能包含扫描码，不建议公开分享。
- 多键盘映射和首次选屏已做自动测试，尚需实际鸿蒙设备、Mac 键盘与多屏 Windows 锁屏环境验收；设备与系统对键盘来源的支持可能不同。
- GitHub 沿用公开未签名 HAP 发布方式，需自行签名安装；正式签名 APP 供应用市场提交，不代表已通过应用市场审核。

构建、测试及签名核验结果见 [发布核验记录](2.0.3-2000003-verification.md)。

# 鼠标模式触屏拖拽

- 轻点一次后，在 450 ms、48 vp 范围内再次按下可成为拖拽候选。之前为 340 ms、40 vp；单击会等待该窗口结束后发送，最多增加 110 ms 等待。远距离或超时的下一次按下仍按独立操作处理，单指长按 600 ms 保持右键。
- 候选期间，小于 18 vp 的移动只用于判断手势，不移动本地或远端鼠标。达到阈值时先在第二次按下的远端鼠标位置发送左键按下，再一次发送累计位移；首个移动不受普通 16 ms 限速影响。松手或取消释放左键；未达阈值松手仍是双击，取消不产生点击。
- 普通非候选的指针移动、触摸模式、实体鼠标、双指操作、缩放与中心跟随保留现有路径。取消、切屏和会话退出仍由原有清理路径释放按键。
- `input` 诊断记录候选结果、上次轻点的相对时间、触点相对距离（无绝对坐标）、触发拖拽的时间和距离，以及长按右键来源。日志遵循现有诊断开关，不记录输入文字或屏幕内容。时间、距离可用于区分窗口超时、触点过远与候选被取消，但不能单凭发送记录断定远端实际执行。
- 回归包含真实状态机的定时器、双击、不同点击间隔/距离、阈值前后移动顺序、中心跟随、限速、取消及长按；仍需在用户设备上测试真实输入法/系统手势以及远端资源管理器拖拽和双击。

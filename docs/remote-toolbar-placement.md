# 远控主功能栏的位置与收放

仅调整主功能栏“控”，保留现有淡蓝配色、键盘分段入口、输入处理和“键”快捷栏。

- 手机与平板：横竖屏均为底部居中的横向功能栏；默认位置收起后为右下角“控”入口。
- PC：普通大小窗口与全屏均为顶部居中的横向功能栏，可收起为“控”。不再按 840 vp 切换到不可收起的固定侧栏。
- 窄 PC 全屏窗口的功能栏会下移一行，以避让右上角单独的退出全屏按钮；无边框窗口同样避让独立窗口控制按钮。
- PC 保留“已固定／自动收起”。未固定、鼠标位于远控画面且没有菜单、拖动或按键操作时，约 5 秒自动收起；普通窗口也适用。
- 二级菜单跟随实际按钮位置，优先在下方或上方展开，仍受窗口、字体和键盘可用区域限制。

## 拖动位置

主功能栏展开与收起后均支持拖动。位置记录为当前可拖动范围中的相对坐标，在当前“服务器 + 远端设备”的偏好文档中保存为 `remote-toolbar-position-v1`；未独立修改时继承旧的全局位置。拖动结束时保存，不在逐帧移动中写入磁盘。重连、窗口缩放、折叠/旋转、输入法改变可用高度、进入或退出全屏时保留选择，并重新计算到有效区域内。

位置偏好缺失、格式损坏、非有限数值或超出范围时安全使用设备默认位置；读取或保存偏好失败不能中断远控会话。诊断只记录保存结果，不记录远端数据。

与官方一致的是默认移动端底部、桌面端顶部和各尺寸均能收起的交互方向；继续保留 StarRustDesk 的“控”入口与自由拖动，不声称逐像素复制官方的顶部/四边停靠实现。

自动测试验证布局与状态逻辑，ArkTS 构建验证接口使用。真实设备视觉、鼠标命中和软键盘避让需单独验证。

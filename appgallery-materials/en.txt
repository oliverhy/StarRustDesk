[App name]
芝麻远控

[Brief introduction]
Remote desktop control and file transfer for HarmonyOS.

[Full introduction]
芝麻远控 (previously StarRustDesk) is a remote control client for HarmonyOS phones, tablets and computers. Connect to devices running a compatible RustDesk host to view the remote desktop, use applications and transfer files. Designed for remote work, personal device management and remote assistance.

Key features

1. Cross-platform remote control
Connect to Windows, macOS, Linux and Android devices. Available controls depend on the remote operating system, client version and permissions.

2. Touch and keyboard/mouse controls
Choose touch mode, mouse mode or a virtual mouse. Use zoom, scrolling, drag gestures and a keyboard shortcut bar, or connect a compatible physical keyboard, mouse or touchpad.

3. Multiple displays and fullscreen viewing
Switch between remote monitors, zoom and pan the desktop, and use portrait, landscape or fullscreen layouts. View-following controls help you navigate an enlarged desktop.

4. Two-way file transfer
Send local files to the remote device or download remote files to your device. Work with multiple files and folders, view transfer progress, speed and history, and cancel transfer tasks.

5. Saved connection management
Save frequently used devices, organize them into groups, and search, sort or edit connections. Back up saved connections with encrypted export and import.

6. Custom connection settings
Use self-hosted ID/relay servers or direct IPv4/IPv6 connections. Import and export server settings, and view connection type, frame rate and decoder information.

7. Languages and dark mode
Choose Simplified Chinese, Traditional Chinese or English. The interface follows your system language by default and also supports manual selection. Dark mode is available.

Before you connect
This app acts as a controller only; it does not allow this HarmonyOS device to be remotely controlled. The remote device must run an enabled, compatible client. Some features require remote support and permission. Connection behavior depends on your network, device system and remote configuration.
Only connect to devices you own or have permission to access. 芝麻远控 is independently developed and is not an official RustDesk app.
